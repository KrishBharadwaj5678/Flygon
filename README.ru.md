## <img src="https://github.com/KrishBharadwaj5678/Flygon/raw/main/readme/gifs/gettingStarted.gif" width="35"/> Начало работы

### 1️⃣ Клонирование репозитория

```bash
git clone https://github.com/KrishBharadwaj5678/Flygon.git
```

### 2️⃣ Переход в проект

```bash
cd Flygon
```

### 3️⃣ Добавление в Unity Hub

- Откройте **Unity Hub**, нажмите **Add** и выберите клонированную папку **Flygon**

### 4️⃣ Открытие проекта

- После завершения импорта файлов Unity откройте основную сцену из папки **Assets**

### 5️⃣ Запуск проекта

- Нажмите кнопку **Play** в Unity Editor, чтобы запустить Flygon

## <img src="https://github.com/KrishBharadwaj5678/Flygon/raw/main/readme/gifs/howItWorks.gif" width="35"/> Как это работает

1️⃣ Откройте **Flygon** и предоставьте доступ к камере для работы AR.

2️⃣ Наведите камеру на окружающее пространство.

3️⃣ Выберите дракона и свободно управляйте его полётом в воздухе.
