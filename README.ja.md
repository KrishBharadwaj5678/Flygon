## <img src="https://github.com/KrishBharadwaj5678/Flygon/raw/main/readme/gifs/gettingStarted.gif" width="35"/> はじめに

### 1️⃣ リポジトリをクローン

```bash
git clone https://github.com/KrishBharadwaj5678/Flygon.git
```

### 2️⃣ プロジェクトへ移動

```bash
cd Flygon
```

### 3️⃣ Unity Hubに追加

- **Unity Hub**を開き、**Add**を選択して、クローンした**Flygon**フォルダを選択します。

### 4️⃣ プロジェクトを開く

- Unityによるファイルのインポートが完了したら、**Assets**フォルダからメインシーンを開きます。

### 5️⃣ プロジェクトを実行

- Unity Editorの**Play**ボタンを押してFlygonを起動します。

<img src="https://github.com/KrishBharadwaj5678/Flygon/raw/main/readme/gifs/divider.gif" width="100%"/>

## <img src="https://github.com/KrishBharadwaj5678/Flygon/raw/main/readme/gifs/howItWorks.gif" width="35"/> 使い方

1️⃣ **Flygon**を開き、AR機能のためにカメラへのアクセスを許可します。

2️⃣ カメラを周囲の空間に向けます。

3️⃣ ドラゴンを選び、空中を自由に飛ばして操作します。
