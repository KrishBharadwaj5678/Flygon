## <img src="https://github.com/KrishBharadwaj5678/Flygon/raw/main/readme/gifs/gettingStarted.gif" width="35"/> Getting Started

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/KrishBharadwaj5678/Flygon.git
```

### 2️⃣ Navigate to the Project

```bash
cd Flygon
```

### 3️⃣ Add to Unity Hub

- Open **Unity Hub**, select **Add**, and choose the cloned **Flygon** folder

### 4️⃣ Open the Project

- Once Unity finishes importing the project files, open the main scene from the **Assets** folder

### 5️⃣ Run the Project

- Press the **Play** button in Unity Editor to launch Flygon
