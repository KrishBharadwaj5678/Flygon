## <img src="https://github.com/KrishBharadwaj5678/Flygon/raw/main/readme/gifs/gettingStarted.gif" width="35"/> Primeiros Passos

### 1️⃣ Clonar o Repositório

```bash
git clone https://github.com/KrishBharadwaj5678/Flygon.git
```

### 2️⃣ Acessar o Projeto

```bash
cd Flygon
```

### 3️⃣ Adicionar ao Unity Hub

- Abra o **Unity Hub**, selecione **Add** e escolha a pasta clonada **Flygon**.

### 4️⃣ Abrir o Projeto

- Após o Unity terminar de importar os arquivos, abra a cena principal na pasta **Assets**.

### 5️⃣ Executar o Projeto

- Pressione o botão **Play** no Unity Editor para iniciar o Flygon.

<img src="https://github.com/KrishBharadwaj5678/Flygon/raw/main/readme/gifs/divider.gif" width="100%"/>

## <img src="https://github.com/KrishBharadwaj5678/Flygon/raw/main/readme/gifs/howItWorks.gif" width="35"/> Como Funciona

1️⃣ Abra o **Flygon** e conceda permissão para acessar a câmera para utilizar os recursos de AR.

2️⃣ Aponte a câmera para o ambiente ao seu redor.

3️⃣ Escolha um dragão e voe livremente com ele pelo ar.
